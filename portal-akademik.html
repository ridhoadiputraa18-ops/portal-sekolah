Input & rekap nilai

Guru cukup memasukkan nilai komponen. Sistem menghitung nilai akhir setelah tombol Submit Nilai ditekan.

75Batas ketuntasan contoh
Rumus: Nilai Akhir = (Tugas × 25%) + (UTS × 30%) + (UAS × 45%).
Contoh: Tugas 85, UTS 80, UAS 90 → (85 × 0,25) + (80 × 0,30) + (90 × 0,45) = 21,25 + 24 + 40,5 = 85,75. Nilai disimpan dengan dua angka desimal.
Predikat contoh: A = 90–100; B = 80–89,99; C = 75–79,99; D = di bawah 75. Ketuntasan: tuntas jika nilai akhir ≥ 75.
Peringkat: rata-rata nilai akhir semua mapel yang tersedia, diurutkan dari besar ke kecil. Jika rata-rata sama, peringkat sama. Aturan bobot, predikat, dan KKM dapat disesuaikan kebijakan sekolah.
